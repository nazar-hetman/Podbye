Podbye — local disk analysis and cleanup

WHAT THIS INSTALLS
  Podbye has no cloud service and sends no telemetry. Analysis and cleanup run
  on this computer and do not need an account or internet connection.

  AI can run on this computer, or you may configure an AI runtime on another
  computer you own on your private local network, such as Ollama. Podbye does
  not use public AI endpoints. If you choose a private-LAN AI server,
  information needed for AI analysis is sent to that server over your local
  network.

BEFORE YOU START
  Podbye is beta software that moves files. Cleanup uses the Windows Recycle
  Bin by default, so items can be restored. Emptying the Recycle Bin is an
  optional, separately confirmed permanent action and cannot be undone. If
  Windows cannot accept a selected item in the Recycle Bin, it can remove that
  item permanently; Podbye reports that outcome. Please make sure anything you
  cannot lose is backed up, as you would with any tool that touches your files.
