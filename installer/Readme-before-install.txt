Vigil — local disk analysis and cleanup

WHAT THIS INSTALLS
  Vigil runs entirely on this computer. It collects nothing, sends nothing,
  and needs no account or internet connection.

BEFORE YOU START
  Vigil is beta software that moves files. It never deletes permanently —
  everything it cleans goes to the Recycle Bin and can be restored — but
  please make sure anything you cannot lose is backed up, as you would with
  any tool that touches your files.
